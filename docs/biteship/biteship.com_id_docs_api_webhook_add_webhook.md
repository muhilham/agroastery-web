# Add Webhook

This endpoint allows you to add a new webhook to your account.

## Create a new webhook [​](https://biteship.com/id/docs/api/webhook/add_webhook\#create-a-new-webhook "Direct link to heading")

To add a new webhook to your account, follow these steps:

1. Navigate to the Biteship dashboard integration page at **[Integration Page](https://dashboard.biteship.com/integrations)**

2. Click on the "Pengaturan" (Settings) button to access the webhook configuration section
![Biteship Generate New Token for API Image](https://biteship.com/id/assets/images/webhook_1-8cde3e47d0758c98396afbf97a0f0237.png)
3. Click "Tambah Webhook" button to add a new webhook
![Biteship Generate New Token for API Image](https://biteship.com/id/assets/images/webhook_2-48fbe035b45057a6dc7181ac3fe1d775.png)
4. In the webhook configuration area, you'll find options to:

   - Enter the URL where you want to receive webhook notifications
   - Select the specific events you want to be notified about (e.g., order status changes, price updates)
   - Set up any necessary authentication for your webhook endpoint![Biteship Generate New Token for API Image](https://biteship.com/id/assets/images/webhook_3-37fd9ef1c76e75e3dae8993c0ab0d870.png)
5. After configuring your webhook settings, click the "Save" or "Add Webhook" button to activate it


Remember to ensure that your webhook endpoint is properly set up to receive and process the incoming data from Biteship.
