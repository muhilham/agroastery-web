# Play Webhook

This webhook is triggered when a play event occurs in the system.

## Update Webhook [​](https://biteship.com/id/docs/api/webhook/play_webhook\#update-webhook "Direct link to heading")

To update the webhook, you need to see there's a yellow button on each order. Click the button to update the webhook based on the **[Webhook event type](https://biteship.com/id/docs/api/webhook/overview)**. Each button will update the webhook based on the event type.

**Make sure to activate your "Mode Testing" toggle at the sidebar to test the webhook.**
