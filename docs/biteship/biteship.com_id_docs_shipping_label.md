# Shipping Label

Biteship does not provide a Shipping Label API, so you'll need to set up your own shipping label system. However, if you prefer not to create your own shipping labels, you can use Biteship's pre-designed labels available for download on the dashboard.

Here are your options for shipping labels:

1. Create your own: Implement a custom shipping label system that integrates with your existing workflow.
2. Use Biteship's labels: Access and download ready-to-use shipping labels directly from the Biteship dashboard.

Whichever option you choose, ensure that your shipping labels include all necessary information for successful delivery, such as sender and recipient details, package information, and tracking numbers.
