---
name: Branch Strategy
description: Stay on current working branch, do not create new branches for features
type: feedback
---

Do not create a new git branch for feature work. Stay on the current active branch.

**Why:** User preference — keeps work consolidated on the branch already in use.

**How to apply:** When starting implementation, skip any step that creates a new branch. Commit all work directly to the current branch (`claude/review-pr-7AjrY` for the Biteship lifecycle work, or whatever branch is active at the time).
